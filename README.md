# 🍱 Home Food Delivery

A Flutter application that connects **home cooks (Hosts)**, **customers**, and **shoppers** in a seamless home-cooked food ordering ecosystem.

## ✨ Features

- **Customer** — Browse home-cooked meals, add to cart, place and track orders
- **Host** — List meals, manage menu items and incoming orders
- **Shopper** — View available delivery tasks and manage deliveries

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| Flutter | Cross-platform UI framework |
| Provider | Lightweight state management |
| GoRouter | Declarative navigation & routing |
| Google Fonts | Poppins & Inter typography |
| Flutter SVG | SVG icon rendering |

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/rimuakter057/home_food_delivery.git

# Navigate to the project
cd home_food_delivery

# Install dependencies
flutter pub get

# Run the app
flutter run
```

**Requirements:** Flutter SDK `^3.9.2` · Dart SDK `^3.9.2`
